# rank-lib-js

Библиотека JavaScript для **подсчёта уникальных строк по маске** и **получения строки по её индексу** без генерации предшествующих вариантов. Работает в Node.js (ESM и CommonJS) и прямо в HTML через один браузерный JS-файл.

- `count(mask, custom?) → bigint` — число уникальных строк.
- `generate(mask, index, custom?) → string` — строка по нулевому индексу `bigint`.
- `compileMask(mask, custom?) → CompiledMask` — компиляция один раз для многократного обращения к индексам.

Использует ε-NFA, ленивую детерминизацию в DFA и динамическое программирование. Даже если необязательные части дают одинаковые строки несколькими способами, каждая строка учитывается **один раз**.

## Требования и установка

Node.js **20+**. Сторонних зависимостей нет.

```bash
git clone https://github.com/birdiecode/rank-lib-js.git
cd rank-lib-js
npm ci
npm run build
npm test
```

При использовании как локальной зависимости другого проекта:

```bash
npm install /path/to/rank-lib-js
```

> Библиотека пока не опубликована в npm. `npm install rank-lib-js` из публичного реестра **не предполагается**. При установке из GitHub нужен доступ к репозиторию (если он приватный).

## Node.js: ESM

```js
import { count, generate, compileMask } from 'rank-lib-js';

const total = count('?d{8,10}');
console.log(total.toString()); // 11100000000

console.log(generate('[ab]{1,3}', 0n));  // a
console.log(generate('[ab]{1,3}', 3n));  // ab

const compiled = compileMask('ABC?d{5,7}');
console.log(compiled.total.toString()); // 11100000
console.log(compiled.at(0n));           // ABC00000
console.log(compiled.at(99999n));       // ABC99999
```

Можно импортировать напрямую из проекта: `import { count } from './src/index.js'`.

## Node.js: CommonJS

После `npm run build`:

```js
const { count, generate } = require('rank-lib-js');
console.log(count('?d{2}').toString());  // 100
console.log(generate('?d{2}', 99n));    // 99
```

## HTML: один JS-файл

Сборка `dist/rank-lib.js` — автономный UMD-скрипт без npm и сборщика на стороне браузера. Подключите обычным `<script>`:

```html
<!doctype html>
<html lang="ru">
<head><meta charset="utf-8"><title>rank-lib-js</title></head>
<body>
  <output id="result"></output>
  <script src="./rank-lib.js"></script>
  <script>
    const { count, generate, compileMask } = window.RankLib;
    const mask = '[ab]{1,3}';
    document.querySelector('#result').textContent =
      `${count(mask).toString()} строк, индекс 3: ${generate(mask, 3n)}`;
  </script>
</body>
</html>
```

Скопируйте `dist/rank-lib.js` рядом со своим HTML-файлом. Для готовой демонстрации откройте **[`demo/index.html`](demo/index.html)**: она подключает `../dist/rank-lib.js`, содержит ввод маски и пользовательских наборов, отображает количество, результат по индексу и следующие 11 строк. После клонирования выполните `npm run build`; без сборки библиотеку всё равно можно использовать из уже закоммиченного `dist/rank-lib.js`.

## Синтаксис масок

| Маска | Значение |
|---|---|
| `abc` | фиксированная строка `abc` |
| `?l` | латинские `a-z` (26) |
| `?u` | латинские `A-Z` (26) |
| `?d` | цифры `0-9` (10) |
| `?s` | печатные ASCII-спецсимволы, включая пунктуацию и пробел (33) |
| `?a` | все 95 печатных ASCII-символов, включая пробел |
| `?h` | `0-9a-f` |
| `?H` | `0-9A-F` |
| `?1` … `?9` | пользовательские наборы, передаваемые в аргументе `custom` |
| `[abc]` | ровно один из `a`, `b`, `c` |
| `[a-z0-9]` | один символ из указанных диапазонов |
| `?d{3}` | ровно 3 цифры |
| `?d{2,4}` | от 2 до 4 цифр |
| `?d{0,1}` | необязательная цифра |
| `??` | буквальный `?` |
| `\[` | буквальный `[` (в JS-строке пишется `'\\['`) |

Квантификатор `{min,max}` действует **только на один предыдущий символ или набор**. Группы вида `(?l?d){2,3}` и альтернативы вида `(ab|cd)` пока не поддерживаются.

Примеры:

```js
count('[ab]{1,3}'); // 14n
count('[a]{0,1}[a]{0,1}'); // 3n: '', 'a', 'aa'
count('ABC?d{5,7}'); // 11100000n

const custom = { '1': 'abcdef', '2': '012345' };
count('?1{2}?2{2}', custom);       // 1296n
generate('?1{2}?2{2}', 0n, custom); // 'aa00'
```

Повторяющиеся символы внутри наборов не увеличивают количество результатов. Например, `[aaa]` содержит один вариант.

## Индексация и порядок

1. Сначала строки меньшей длины.
2. В пределах одной длины — детерминированный порядок алфавита маски (порядок первого появления символа среди её наборов). Это **не** Unicode-сортировка и **не** алфавитная сортировка по локали.
3. Индексы начинаются с `0n`; последний индекс — `count(mask) - 1n`.

Для `[ab]{1,3}` индексы `0..5` дают `a`, `b`, `aa`, `ab`, `ba`, `bb`, далее идут восьми трёхсимвольных варианта.

`generate()` принимает именно **BigInt**. Например, `generate('?d{2}', 42n)` корректно, а `generate('?d{2}', 42)` вызовет `TypeError`. Число комбинаций может быть гораздо больше `Number.MAX_SAFE_INTEGER`.

### Повторное использование компиляции

```js
const compiled = compileMask('?l{8,10}');
console.log(compiled.total);     // bigint
console.log(compiled.minLength); // 8
console.log(compiled.maxLength); // 10
console.log(compiled.at(0n));    // aaaaaaaa
console.log(compiled.at(1n));    // aaaaaaab
```

Если требуется много произвольных индексов одной маски, вызывайте `compileMask()` один раз. Вызовы `generate(mask, index)` компилируют маску заново.

## Ограничения и ошибки

- Длина — число **Unicode-кодовых точек**, а не байтов UTF-8 (например, `😀` — одна позиция). Для систем, ограничивающих пароль по UTF-8 байтам, нужна отдельная проверка длины закодированной строки.
- Максимальная суммарная длина — **128 кодовых точек**. Лимиты сложности: 1500 NFA-состояний, 10 000 DFA-состояний и 250 000 записей мемоизации; слишком сложная маска вызывает ошибку, чтобы избежать неконтролируемого расходования памяти/CPU.
- Некорректные наборы, диапазоны или квантификаторы выбрасывают `Error`; неверный тип индекса — `TypeError`, индекс вне диапазона — `RangeError`.
- Входная маска может быть пустой: тогда ровно одна строка — пустая, с индексом `0n`.
- Порядок перечисления зависит от определения стандартных/пользовательских наборов; при сохранении диапазонов индексов храните и саму маску, и её наборы, и версию библиотеки.
- Библиотека выполняет **индексирование строк**, а не проверку паролей, сетевую аутентификацию или работу с хэшами.

## CI и скачивание артефакта

GitHub Actions запускается при `push` в `main`, для Pull Request и вручную (`workflow_dispatch`). Выполняются:

1. `npm ci`
2. `npm run check` — сборка и Node.js-тесты
3. проверка, что закоммиченные сборки совпадают с результатом сборки
4. публикация артефакта **`rank-lib-js-browser`**, содержащего `dist/rank-lib.js` и `demo/index.html`.

Загрузить артефакт можно на вкладке **Actions → CI → нужный запуск → Artifacts**. Внутри ZIP сохраняется структура каталогов, поэтому достаточно распаковать и открыть `demo/index.html` в браузере.

Сборка локально: `npm run build`. Тесты: `npm test`. Полная проверка: `npm run check`. Чтобы подготовить npm-пакет: `npm pack` (публикация в npm **не настроена**).
